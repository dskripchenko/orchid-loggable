# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project follows [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

Entries for releases published before this file existed were reconstructed from
the tagged commit history.

## [v1.2.1] - 2026-07-21

### Added
- A README that explains what the package does, how to install it and how to use it.

## [v1.2.0] - 2026-07-21

### Changed
- Supported versions moved to the canonical matrix: PHP 8.2-8.5 with Laravel 11, 12 and 13.

### Added
- GitHub Actions pipeline covering the whole support matrix.

## [1.1.3] - 2025-05-12

### Added
- Laravel 12 support.

## [1.1.2] - 2024-08-06

### Added
- Facade method for recording a change entry by hand.

## [1.1.1] - 2024-08-06

### Fixed
- Corrected the change-log observer.

## [1.1.0] - 2024-08-06

### Changed
- Simplified the change-log model.

## [1.0.0] - 2024-08-06

### Added
- First stable release: change-log model, observer, and Orchid screens, layouts and
  filters for browsing the recorded history.

## [0.0.1] - 2024-07-30

### Added
- Initial release.
